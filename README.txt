# Exam Path Hub starter website

## Files
- `index.html`: searchable exam homepage
- `style.css`: responsive mobile-friendly design
- 15 separate exam pages (`*.html`)

## Publish on GitHub + Netlify
1. Extract this ZIP.
2. In your GitHub repository, upload all extracted files to the repository root (same place as `index.html`).
3. Commit changes. If Netlify is connected to this repository, it should deploy automatically.
4. Open your Netlify website and test a few exam cards.

This is a starter template, not a complete question bank. Verify syllabus and updates from official exam authorities. Quiz on each page is only a demo question.
